PhysiClaw 的硬件优先采用易于采购、成本低、可靠的标准件；定制件采用 3D 打印。

整套零件约 **¥1,000**（不含运费）。下单前通读装配手册，充分了解硬件结构。采购时逐项对照物料清单，确认无遗漏、数量正确。一旦缺漏就需要补单，并在物流上耗费更多时间。供应商均为淘宝店铺，查看商品详情需登录淘宝账号。

:::caution[3D 打印工艺]
PhysiClaw 的定制件用黑色 **[PA12 尼龙](https://en.wikipedia.org/wiki/Nylon_12)**，以粉末床熔融工艺（**[SLS](https://en.wikipedia.org/wiki/Selective_laser_sintering)** 或 **[MJF](https://en.wikipedia.org/wiki/Multi_Jet_Fusion)**）打印。
常见的 **[FDM](https://en.wikipedia.org/wiki/Fused_filament_fabrication)** 工艺打印出的孔位容易失圆、变形，影响装配。
:::
