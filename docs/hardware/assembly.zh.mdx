PhysiClaw 的硬件采用 [CoreXY](https://corexy.com/) 运动结构：两个电机协同驱动龙门架，电磁铁沿 Z 轴驱动触控笔尖完成点击。整个组装大约需要 **三个小时**。

装配手册提供完整、清晰的步骤，可在线查看或下载 PDF。要查看组装完成的整机，下载 [3D 装配模型（STEP）](/downloads/physiclaw_assembly_3d.zip)，需用 3D 软件打开，推荐免费开源、跨平台的 [FreeCAD](https://www.freecad.org/)。动手前可浏览硬件图集，对整机建立直观印象，或观看[演示视频](https://b23.tv/jnegfgC)了解实际运行效果；[装配视频](https://www.bilibili.com/video/BV1b7av68E77/)完整记录了组装过程。

:::caution[装配注意事项]
以下几点装配手册已有说明，但值得强调：

- **触控笔尖必须接地**：接到已接地电脑机箱背面的裸露金属，切勿接墙上插座，也切勿接控制板的 GND。
- **调整摄像头位置**：打开系统自带的摄像头预览，确认手机屏幕平整、尽量占满画面，无倾斜或畸变。
- **A/B 同步带张力保持一致**：张力不一致会导致机械臂运动不准确。
- **锁紧电机同步轮**：在紧定螺钉上涂螺纹胶（蓝色可拆型）。电机不断正反转，反复换向容易使螺钉松动，同步轮一旦打滑，运动就会漂移。
:::
