---
title: 最佳实践
description: 如何用好 PhysiClaw。包括当个人助理用、接入编程智能体，以及把例行任务做成 playbook。
---

PhysiClaw 有三种用法：当你的个人助理，作为 MCP 服务接入编程智能体，以及用 playbook 执行反复要做的任务。

## 作为个人助理

PhysiClaw 会在使用中慢慢了解你的偏好。

**把要求说具体。** 说得越清楚，它越少走弯路。尤其记得指明用哪个 app。

:::tip[发信息]
在美团小象超市买一盒三元低脂牛奶 250ml。
:::

**让它「记住」。** 你的偏好、常用地址、特殊要求，凡是希望它长期记着的，直接跟它说「记住」就行，之后每次对话都会用上。

:::tip[发信息]
记住：我不吃辣。
:::

**安排定时任务。** PhysiClaw 可以按计划执行任务，告诉它时间就行。

:::tip[发信息]
每天早上 8:00，告诉我天气。
:::

## 在 Claude Code 或 Codex 里用

如果你已经在用编程智能体，可以把 PhysiClaw 作为 [MCP 服务](/zh/custom/mcp/)接入。智能体跑在电脑上，你直接在终端里就能操控手机。

:::tip[在终端输入]
打开小象超市，告诉我购物车里有什么。
:::

## 把例行任务做成 playbook

凡是要反复做的事，比如每周买菜、每天早上点咖啡，都适合做成 [playbook](/zh/custom/playbooks/)，而不是 skill。Skill 每一步都交给模型处理。Playbook 则把固定步骤录下来，只在需要判断的地方才调用模型。这样 token 消耗能降低 50 到 100 倍，执行也快好几倍。你可以让编程智能体帮你写 playbook，先在自己手机上跑通一遍，确认没问题再启用。
